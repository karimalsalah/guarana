Play the Switch 2 Ocarina of Time on your PC or laptop

Guarana is a free, open-source Switch 2 emulator tuned for laptop and handheld graphics. Download it, bring your own keys, firmware and game, and you are playing in about five minutes. Here is exactly what to click and what speed to expect.

The 5-minute path

Today (v20.0.2) the download is a zip. A one-click Windows installer, Guarana Setup, arrives with the next release; this path then gets shorter.

  1. Download

    Get the Windows x86-64 zip from the latest release, the only official download. Check it against SHA256SUMS on the same page.

  2. Extract and run

    Extract to a writable folder and start guarana.exe.

  3. Bring your own keys and firmware

    Tools → Install Decryption Keys, then Tools → Install Firmware, with files you dumped from hardware you own. Guarana includes neither and will not tell you where to find them.

  4. Add your game

    Double-click the empty game list, pick the folder with your own game dump, start The Legend of Zelda: Ocarina of Time. Each new area compiles shaders and hitches once; later visits use the cache (why, and what helps).

  5. Use the Ocarina of Time defaults

    For this game the global-memory fix (EDEN_NX2_GM=11) is already on, and extrapolation (EDEN_NX2_EXTRAPOLATE=1) is on in the shipped nx2_switches.txt. Then go to Emulation → Configure… → Graphics: Enable Frame Generation on, Frame Generation Multiplier 3, Target Frame Rate 60. Put your own switch lines in %APPDATA%\guarana\nx2_switches.txt, not the copy next to the executable.

Control it with a pad: controller setup. Own a handheld: what to expect.

What to expect on a laptop with integrated graphics

  • Not 60 fps from the game. The game itself renders about 23 fps in Hyrule Field on the Arc 140T with frame generation off, and about 26.7 to 28 in gameplay with it on (v20, live readings, not a same-spot A/B). Frame generation makes motion smoother at 60 Hz; the game still reads input at its own rate.
  • The first visit to an area hitches while the driver compiles shaders, 0.4 to 1 s per pipeline on Intel. Judge smoothness on the second pass.
  • Some games work, most are unmeasured. Every number here is from Ocarina of Time. Other games may run; we have not measured them.
  • Reports from others vary with hardware and build, and are not ours to vouch for. Yours helps: send a device report.

Questions people ask

Can I play the Switch 2 Ocarina of Time remake on a PC?

Yes, with a Switch 2 emulator, and you need your own copy. Guarana runs it on Windows 11. You supply the keys, firmware and game, dumped from a console and a game you own. On our test laptop (Core Ultra 9 285H, Arc 140T) one shader fix took Hyrule Field from 14.8 to 22.8 game fps with frame generation off. That is one laptop and one scene.

What do I need to play it on a laptop or handheld?

A Windows 11 x64 PC or handheld with a Vulkan GPU and a current driver, 16 GB of RAM at the very least (our laptop has 32 GB), and your own keys, firmware and game dumped from hardware you own. Guarana contains none of them and does not tell you where to get them.

Where do I get the keys and firmware?

Dump your own from hardware you own. Nobody in this project will point you to downloads, and requests for them are closed.

Is the best Switch 2 emulator Guarana, Lichii, Eden or Eglantine?

They are one family: Guarana forks Lichii, Lichii builds on Eglantine, Eden and yuzu. None is a finished product. Guarana is the one tuned and measured for laptop and handheld integrated GPUs, with paired before-and-after numbers. For a large discrete graphics card we have no measurements, so try the family and compare.

Emulator or recompilation: which should I use for Ocarina of Time?

An emulator runs the game as you dumped it and also runs other Switch 2 games, so it is the more general tool. A recompilation turns one game's code into a native Windows program, which can be faster on that one game but is a separate project per game that we do not run or measure. Both need a dump from hardware you own. If a recompilation covers your version of the game and you only want that game, it is worth trying.

Does frame generation add input lag?

Guarana's frame generation for Ocarina of Time extrapolates: it moves the newest real frame forward along the game's motion vectors and shows each real frame as soon as it is ready, instead of holding one back like interpolation does. It does not make the game react faster, and we have not published a latency figure because we have not measured one the same way.

What settings should I use?

On the Arc 140T laptop: Enable Frame Generation, Frame Generation Multiplier 3, Target Frame Rate 60. The global-memory fix turns itself on for Ocarina of Time, and extrapolation is on in the shipped switches file. Other devices are untested, so change one setting at a time and report what you see.

Play it, then help it get better

Guarana is free and open source (GPL-3.0-or-later). It ships no keys, firmware or games: you bring your own, dumped from hardware you own.

  • Download: the latest release is the only official download.
  • Stuck? Ask in the Discord (bugs and device reports stay on GitHub so they are tracked).
  • Test: a device report needs no code and puts your device on the leaderboard.
  • Contribute with your AI agent: one sentence gets Claude Code, Codex, Gemini CLI, Cursor or Copilot to a pull request. Start at the agents page, or see open wins with numbers.
