Switch 2 emulation on the Legion Go 2

Lenovo's 2025 handheld comes with a Ryzen Z2 Extreme (Radeon 890M class) or a Ryzen Z2 (Radeon 780M class). Untested so far; say which model you have when you report.

Untested Nobody has reported it yet. Send a report.

What we know

  • Untested on this device. Send a report: yours would be the first.
  • The Z2 Extreme chip has one third-party report from another handheld: about 30 fps in Ocarina of Time on a ROG Xbox Ally X (Lichii #1433). Different cooling and power limits can change the result.

Specs that matter for emulation

Processor
AMD Ryzen Z2 Extreme (8 Zen 5 cores) or Ryzen Z2 (8 Zen 4 cores)
GPU
Z2 Extreme: RDNA 3.5, 16 compute units (Radeon 890M class). Z2: RDNA 3, 12 compute units (Radeon 780M class)
Memory
Up to 32 GB LPDDR5X-8000 (16 GB on Ryzen Z2 models), shared by CPU and GPU
Power
Z2 Extreme: 15–35 W configurable. Z2: 15–30 W
Screen and battery
8.8-inch 1920×1200 OLED at 144 Hz; 74 Wh
OS
Windows 11

From Intel, AMD and device makers' published specs. Power limits vary with model, firmware and mode.

Starting point for settings

Not tuned for this device: it's the setup from the tested Arc 140T laptop. Change one thing at a time and report what helps.

  1. Power

    Plug in and pick the device's highest performance mode. Put the mode and wattage in your report.

  2. Driver

    Use a current AMD graphics driver (AMD Software: Adrenalin Edition, or the package from your device maker) and report its version.

  3. Global-memory routing

    Add EDEN_NX2_GM=11 to nx2_switches.txt next to the emulator, or set it as an environment variable. It is the change behind the measured Arc 140T gain. If a game renders wrongly, remove it first and tell us.

  4. Frame generation

    In the graphics settings, turn on Enable Frame Generation and set Target Frame Rate to 60. Add EDEN_NX2_EXTRAPOLATE=1 for extrapolated frames (motion data is wired up for Ocarina of Time only). Report game fps, not the total with generated frames.

  5. Shaders

    The first visit to an area hitches while shaders compile. Judge smoothness on the second pass.

Notes for this device

  • Switch 2 games are written for an NVIDIA GPU, and AMD drivers expose emulation gaps differently. Upstream Lichii keeps notes on AMD GPUs, with the fixes so far and the open reports: read them before filing a bug.
  • When you compare frame rates, set the log filter to *:Error. Info-level logging costs CPU time in busy scenes (from the same notes).
  • On the 16 GB Ryzen Z2 model, enlarge the Windows page file. Upstream Lichii found that a small page file can make shader builds fail in Ocarina of Time on 16 GB machines (see the AMD notes).

Have one? Send a report

One report turns this page from a guess into data. Include:

  • Device, CPU, GPU and RAM
  • The full graphics driver version (on Intel, like 32.0.101.9175; on Linux, the Mesa version) and the OS
  • Plugged in or on battery, and the power mode or wattage
  • The emulator build, every setting you changed and every EDEN_NX2_* switch you set (or "none")
  • The game and the exact spot, docked or handheld mode, and a screenshot of the scene
  • Average fps and, if you can, p50 and p99 frame times, measured after the scene settled

Never attach keys, firmware, game files, saves, shader caches, or logs that show your user name or folder paths.

Questions

Can the Legion Go 2 run Switch 2 games?

It's untested with Guarana. The Z2 Extreme model's chip has one third-party report from a ROG Xbox Ally X on the upstream Lichii tracker (about 30 fps in Ocarina of Time); the Z2 model's GPU class (Radeon 780M) has none. Send a report and say which model you have.
