    Tools

    AI tools and bots that helped are listed here, apart from the people. A person owns every pull request, so the person is the contributor and the tool is named by its Co-authored-by: or Assisted-by: line.

      How to get on it

      Get one pull request merged: a fix, a test, a device report turned into a benchmark row, a doc. Co-author a commit and you are on it too. Port an upstream fix with its author credited and the author is on it as well. CONTRIBUTING.md has the five-minute start, and the agents page has one command per AI tool.

      What counts: commits since the first day of Guarana, merges excluded. Before that the history is the upstream projects' (Lichii, Eglantine, Eden, yuzu), credited in CREDITS.md. Trailer e-mail addresses are used only to find a GitHub login and are never published.
