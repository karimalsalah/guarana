Open wins

Problems with a number on them. Each card names the scene, where the number is today, where it should go, and where in the code to start. Move one and your name goes into the release notes, the hall of fame and the app's credits.

    How to take one

    Comment on the issue with what you will try, then open a pull request that shows the number moving on the scene, with the baseline next to it. A fix that does not move the number is still welcome as a measurement.

    Only a measured gain on a verified scene ships: tools/bench rows that are valid with scene_ok true, baseline and change back to back. Your name is added when the pull request is merged, or when a merged commit names you in a Co-authored-by: line. See the hall of fame.
