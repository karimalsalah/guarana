Switch 2 emulator on ROG Ally, Legion Go, MSI Claw and Steam Deck

Can a Windows handheld run the Switch 2 Ocarina of Time through an emulator? Not proven yet. This page says what is known, what is only reported by others, and how your device can become data.

Download Guarana Ask in Discord Send a device report

The honest answer

Handhelds are the target, and not one has been measured by the maintainers yet. Switch 2 emulation is heavy: it needs a lot of memory and GPU time, and a handheld shares both with the CPU inside 15 to 30 W. If you hope to play on one, expect to tune, and expect some games not to be playable. What we can give you is the one result we have, the setup that produced it, and a way to turn your attempt into data for everyone.

Starting point for a handheld on Windows

This is the setup from the one tested laptop. It is not tuned for your device. Change one thing at a time.

  1. Install

    Follow the 5-minute path with your own keys, firmware and game.

  2. Power

    Plug in and use turbo or the highest performance mode. Close the handheld’s overlay apps. On 16 GB, enlarge the page file.

  3. Settings

    Enable Frame Generation, multiplier 3, target 60. The shader fix is on for Ocarina of Time by default. Judge smoothness on the second pass through an area, after shaders have compiled.

  4. Controls

    Handheld mode and controller hotkeys are on the roadmap. For now see controller setup.

  5. Report

    Send the game fps (not the total with generated frames), the driver version, the wattage or power mode and a screenshot of the scene.

Have a handheld? Send a device report

One report turns a page of guesses into data and puts your device on the leaderboard.

  • Device, CPU, GPU and RAM
  • Graphics driver version and Windows version
  • Plugged in or on battery, and the power mode or wattage
  • The Guarana build, every setting changed and every EDEN_NX2_* switch (or “none”)
  • The scene, and average game fps measured after it settled

Never attach keys, firmware, game files, saves, shader caches, or logs that show your user name or folder paths.

Questions people ask

Can the ROG Ally, Legion Go, MSI Claw or Steam Deck run Switch 2 games?

We do not know yet. No handheld has been measured by the maintainers. There is one third-party report of about 30 fps in Ocarina of Time on a ROG Xbox Ally X (Radeon 890M-class GPU, upstream Lichii issue 1433) and one of 22-24 fps on the Arc 140V in the MSI Claw 8 AI+ on another build. Every other handheld is untested.

How is this different from Ocarina of Time on Steam Deck as a native port?

Native N64 ports and recompilations of the original game are a different thing: they run the old game as a PC program. Guarana emulates the Switch 2 console to run the Switch 2 remake, which is far heavier, and the Steam Deck is the lowest-powered device on our list.

How much memory does a handheld need?

Switch 2 titles use a large guest memory layout and the integrated GPU takes its share from the same RAM. 16 GB is below the comfortable floor. An upstream report has Ocarina of Time running out of device memory on a ROG Ally with a Radeon 780M, so close everything else and enlarge the page file.

Does Guarana run on Android handhelds or SteamOS?

Release builds are Windows x64. Nothing outside Windows is tested here. We do not have an Android build, and the Steam Deck on SteamOS is untested.

How do I help get my handheld supported?

Run it, then open a device report with the device, GPU, driver, power mode, build, the scene and game fps. A failure is useful data too. Each device page below links a prefilled form.

Which power mode should I use on a handheld?

Plug in and use the highest performance or turbo mode. The CPU and GPU share one power budget, and our only measured results are with the charger connected.
