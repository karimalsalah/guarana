# Guarana

**Эмулятор Nintendo Switch 2, настроенный под встроенные видеоядра.**

Guarana — открытый форк [Lichii](https://github.com/zortos293/Lichii) (ветка `nx2`) для Windows x64. Проект ориентирован на ноутбуки и портативные устройства со встроенной графикой: сначала Intel Arc, затем AMD Radeon. Основные задачи: более ровный темп кадров, генерация кадров, быстрый запуск и более эффективное распределение энергетического бюджета.

> [!IMPORTANT]
> Guarana **не содержит** ключей, прошивки, игр и системных файлов. Нужны собственные, снятые с консоли и с игр, которые вам принадлежат. Проект не связан с Nintendo и проектом Lichii. Юридическое примечание — ниже.

## Что это

- Бесплатный эмулятор с открытым исходным кодом по лицензии GPL-3.0-or-later.
- Настроен под встроенные GPU с общей памятью и ограниченным питанием.
- Требуется Windows x64, процессор с поддержкой AVX2 и актуальный драйвер видеокарты.
- Не содержит ключей, прошивки, игр и системных файлов.

## Результат измерения

Измерено на ноутбуке с Core Ultra 9 285H, встроенным GPU Arc 140T, драйвером Intel 32.0.101.9175 и 32 ГБ памяти. В Hyrule Field из *Ocarina of Time* исправление маршрутизации глобальной памяти (`EDEN_NX2_GM=11`) подняло частоту кадров игры с **14,8 fps** до **22,8 fps**. Сравнение проводилось в одной и той же точке, с опцией включённой и выключенной, при отключённой генерации кадров.

Это данные одного устройства, одной игры и одной сцены. Другие устройства, драйверы, игры и сцены не измерялись. Вы можете [помочь с измерениями](../../docs/BENCHMARKING.md).

## Поддерживаемое оборудование

Протестирован только Arc 140T. Остальные GPU (Arc 140V, Arc B390, Radeon 780M, 880M, 890M и другие) ещё не проверялись. Полезен [отчёт об устройстве](../../docs/DEVICES.md#send-a-device-report). Устройства с 16 ГБ общей памяти ниже рекомендуемого минимума; подробности в [DEVICES.md](../../docs/DEVICES.md).

## Быстрый старт

1. Скачайте последний zip на странице [Releases](https://github.com/karimalsalah/guarana/releases). Это единственный официальный источник.
2. Распакуйте весь zip в папку, куда у вас есть права записи, и запустите **`lichii.exe`**.
3. Установите ключи и прошивку: **Tools → Install Decryption Keys**, затем **Tools → Install Firmware**.
4. Добавьте папку с играми (двойной щелчок по пустому списку) и запустите игру. При первом входе в каждую область шейдеры компилируются и возможны подвисания; дальше они загружаются из кэша.
5. По желанию: включите **Enable Frame Generation** в **Emulation → Configure… → Graphics**.

Настройки, сохранения и кэш лежат в `%APPDATA%\lichii`, в той же папке, что и у оригинального Lichii. Перед переключением между версиями сделайте резервную копию. Все переключатели описаны в [docs/switches.md](../../docs/switches.md), типичные проблемы — в [TROUBLESHOOTING.md](../../docs/TROUBLESHOOTING.md).

## Ключи, прошивка и игры (юридическое примечание)

- Используйте собственные ключи, прошивку и игры, снятые с оборудования, которое вам принадлежит. Guarana их не предоставляет и не принимает их в issues, PR и обсуждениях.
- Запросы и ссылки на защищённые авторским правом файлы, а также вопросы о том, как их получить, не рассматриваются.
- Guarana — независимый проект. Он не связан с Nintendo и проектом Lichii и не одобрен и не спонсируется ими. «Nintendo» и «Nintendo Switch» — товарные знаки Nintendo; они упоминаются только для обозначения совместимости. Полный текст: [LEGAL.md](../../LEGAL.md).

## Как помочь проекту

- **Без кода:** запустите [бенчмарк](../../docs/BENCHMARKING.md) и пришлите результаты либо отправьте [отчёт об устройстве](../../docs/DEVICES.md#send-a-device-report).
- **С кодом:** возьмите задачу с меткой `good first issue`, прочитайте [CONTRIBUTING.md](../../CONTRIBUTING.md) и следуйте инструкции по [сборке](../../docs/Build.md).
- **ИИ-агенты:** сначала прочитайте [AGENTS.md](../../AGENTS.md), [архитектуру](../../docs/ARCHITECTURE.md) и [политику в отношении ИИ](../../docs/AI_POLICY.md). За каждый PR отвечает человек.
