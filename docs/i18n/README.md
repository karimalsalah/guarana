## What stays in English

Product names (Guarana, Lichii, Eden), commands, environment variables such as `EDEN_NX2_GM=11`, file names such as `guarana.exe`, menu paths, and URLs are kept in English in every translation, so they match the software and the links work.

## Keeping them in sync

When the English README changes, update the matching translation in the same change, especially the measured numbers, the device list and the quick start steps. Keep the language switcher line at the top of every file.

## Adding a language

1. Copy the structure of [README.de.md](README.de.md), keeping the same sections in the same order.
2. Add the new language to the switcher line at the top of every file in this folder, and to the table above.
3. Keep product names, commands, file names and URLs in English.
