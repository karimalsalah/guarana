# Conventions for Aider

Read AGENTS.md at the repository root before changing anything: it is the source of truth for this
repository (rules, repository map, build and test commands, never-commit list, commit style).
`.aider.conf.yml` loads it read-only for you; by hand: `aider --read AGENTS.md`.
The one-command start for every AI tool is in docs/AI-QUICKSTART.md.
