- Launcher: while a game plays the launcher's window hides, so the game is the one window, Alt+Tab
  entry and taskbar button; it comes back to the front when the game exits, as before. It hides at
  the game's first frame (for builds without a launcher session, when the game's window takes the
  foreground), so the loading progress stays reachable until then and a load error before the game
  starts leaves the launcher where it was. Starting the launcher again shows it at any time.
